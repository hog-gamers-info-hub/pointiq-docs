# PointIQ User Guide

Use this guide to set up a tournament, enter its squads, create matches, and add the screenshots used during match review.

## Guide topics

- [Create a tournament](/guide/create-tournament) — set up a tournament, enter squad/team names, and create or continue a match.
- [Add screenshots](/guide/add-screenshots) — add lobby and result screenshots, adjust their crops, and manage saved images.
- [Auto-calculate results](/guide/auto-calculate) — continue to the results calculation workflow.
- [Enter results manually](/guide/manual-results) — enter results without the screenshot workflow.
- [Review and finalize](/guide/review-finalize) — check calculated or manual values, correct issues, apply point adjustments, and finalize a match.
- [View standings](/guide/standings) — view tournament standings.
- [Export results](/guide/export-results) — export tournament results.
- [Use templates](/guide/templates) — use tournament templates.

For first-time setup, start with [Create a tournament](/guide/create-tournament). When you reach Match Review, continue with [Add screenshots](/guide/add-screenshots).
