# Troubleshooting

Having trouble using PointIQ? Follow the relevant instructions below.

All tournament management and result calculation actions described here take place inside the PointIQ Android application.

## Automatic Calculation

### Auto Calculate cannot start

**Possible reason:** The match does not have the required result screenshots.

**What to do:**

1. Open the affected match in PointIQ.
2. Check whether the result screenshots have been added.
3. Add the required result screenshots if they are missing.
4. Return to the result calculation workflow.
5. Try Auto Calculate again.

If the problem continues, contact support.

See [Automatic Calculation](/guide/auto-calculate).

### PointIQ is not recognizing screenshot information correctly

**Possible reason:** Screenshot cropping, image quality, or text recognition may be affecting the result.

**What to do:**

1. Review the screenshot selected for calculation.
2. Check that the relevant result information is visible.
3. Correct the screenshot crop if necessary.
4. Replace unsuitable screenshots with clearer versions if available.
5. Try automatic calculation again.
6. Review and manually correct any remaining errors before finalization.

See [Add Screenshots](/guide/add-screenshots).

## Squad Matching and Result Corrections

### A squad was assigned incorrectly

**What to do:**

1. Open the calculated match results before finalization.
2. Review the squad assignments.
3. Correct incorrect or unassigned squads using the available editing controls.
4. Review the corresponding values before finalizing.

See [Review and Finalize](/guide/review-finalize).

### The position or elimination count is incorrect

**What to do:**

1. Review the calculated result.
2. Identify the incorrect squad or row.
3. Correct the supported position or elimination values.
4. Verify the updated result.
5. Finalize only when the result is correct.

See [Manual Result Entry](/guide/manual-results).

### I want to calculate results manually

PointIQ provides an Enter Results Manually option.

Follow the instructions in [Manual Result Entry](/guide/manual-results).

## Finalization

### Finalize Result is unavailable

**Possible reason:** The match result may not meet the application's finalization requirements.

**What to do:**

1. Review all result rows.
2. Check for missing or incorrect squad assignments.
3. Review positions, eliminations, and other required values.
4. Check any validation information displayed by PointIQ.
5. Correct the issues shown by the application.
6. Try finalizing again.

If the button remains unavailable and no clear explanation is displayed, contact support.

See [Review and Finalize](/guide/review-finalize).

### I finalized a match with incorrect results

Finalized results are normally read-only. Do not assume that the application supports editing a finalized match.

Contact PointIQ support to explain the situation.

## Tournament Standings

### My tournament standings appear incorrect

**What to check:**

1. Confirm that the expected matches have been finalized.
2. Review the match results included in the standings.
3. Check bonus or penalty adjustments.
4. Review the tie-breaking rules.

PointIQ uses total points, total kills, number of Booyahs, and total placement points as tie-breakers, in that order.

See [Tournament Standings](/guide/standings).

## Screenshots and Recovery

### My screenshots are unavailable after reinstalling the app or clearing app data

**Possible reason:** The screenshot files may no longer be accessible.

**What to do:**

1. Open the relevant tournament and match.
2. Check whether the finalized result data is still available.
3. Check whether the app displays Screenshots unavailable.
4. Do not assume that missing screenshots can always be recovered.
5. Contact PointIQ support if assistance is required.

Screenshot storage and finalized result data are separate concerns. The presence of a finalized result does not guarantee that its original screenshots remain accessible.

See [Add Screenshots](/guide/add-screenshots).

## Downloads and Designs

### I cannot download a result

**What to do:**

1. Open the relevant result download screen in PointIQ.
2. Check that the required match or overall standings are available.
3. Select the intended result view.
4. Choose a supported design.
5. Try the PNG download again.

If downloading still fails, report the issue through the feedback website.

See [Export Results](/guide/export-results).

### My custom design is not available

**What to check:**

1. Open the result design options.
2. Check whether your custom design was previously saved.
3. Verify that you are viewing the appropriate design selection options.

If a previously saved design is unexpectedly missing, contact support. Recovery is not guaranteed.

See [Design Templates](/guide/templates).

## Still Need Help?

If the problem continues, contact the PointIQ team.

**Email:** [team@point-iq.com](mailto:team@point-iq.com)

**Feedback:** [Submit a Problem Report](https://feedback.point-iq.com/)

When reporting a problem, include:

- A short description of what happened.
- The feature or screen where the problem occurred.
- The steps that led to the problem.
- The app version, if available.
- A relevant screenshot, if available and safe to share.

Do not share passwords, verification codes, or other sensitive account information.
